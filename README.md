## 中央テーブル（配置B）

候補は次の6点です。寸法と価格は画面の候補比較から確認できます。

- RUGHAUS スタンダードテーブル 1750×800×H720
- MODERN DECO skdt01（伸長時）2000×1200×H717
- ONE LUX ラウンド φ1900×H710
- ONE LUX 小判形 2200×1200×H710
- G-FIELD セラミック丸テーブル φ1600×H750

「視点 → 中央」で天板・脚・北側ワゴンを近くから確認できます。「表示 → 中央テーブルのノートPC（6台）」でPCを切り替えられ、初期状態は非表示です。表示設定と候補はブラウザに保存します。削除された候補を保存していた場合はRUGHAUSに戻ります。

50インチ画面は北側のシルバー3段ワゴンの上段、iPad電話・Bluetooth受話器は中段に置き、どちらも中央テーブルへ向けています。ワゴンはユーザー提供写真を参考にした天板幅550×奥行400mmの配置検討用モデルです（モニター台座は480×310mm）。天板の高さは候補テーブルに揃え、背面の電源タップから床のT7まで延長ケーブルを描いています。ワゴンの商品選定・施工配線を確定したものではありません。

## 配置Bの南寄せと収納（2026-10-03）

北東側の収納は16個（4列×4段、積み上げ高さ約1060mm）。[フェローズ 703sブラック](https://www.fellowes.co.jp/product/bankers-box/FE-1009301.html)の外寸345×410×265mmを参考に、白い本体、かぶせ蓋、黒いライン、持ち手穴、記入欄をモデル化しました。箱の品番・積載内容は未確定です。

ゴミ箱3個は、2026-10-04の大型家電ラック更新でラック下へ移動しました（配置A・B共通）。配置Aのデスクは従来のままです。

## 北側の時計とハンガーラック（2026-10-03）

北側の2枚のドア上、中央付近に直径300mmの黒いBRAUN風壁時計を追加しました。中心高さ2350mm、本体奥行45mmで、[BRAUN BC17Bの公式写真・外寸](https://braun-clocks.com/products/bc17-classic-large-analogue-wall-clock-black)を参考に、黒い文字盤、白い数字と時分針、黄色い秒針先端を再現しています。所有されている時計の正確な型番は未確認で、針は表示用に固定しています。

ボックスの北側（後ろ）、掃除機の西隣に、シルバーの簡易ハンガーラックを置きました。幅900×奥行400×高さ1600mm程度を想定した細いパイプのモデルで、上部の横棒・2本の支柱・T字脚とワイヤーハンガー2本で構成しています。品番は未選定です。

## 南東側の機器棚（2026-10-03）

フォンブースP2・南東柱・東側最南デスクに囲まれた隙間へ、幅480×奥行440×高さ900mmの3段棚を配置しました。上段は4本アンテナ付きの大きめのWi-Fiルーター、中段はSwitchBotのハブ・温湿度センサー・人感センサー類、下段は電源タップの配置イメージです。棚内の電源・充電ケーブルも描いています。機器の型番・実寸は未指定のため、外観を簡略化した仮モデルで、画面の数値も表示用です。

「視点 → 機器棚」で拡大確認できます。棚板はブースから50mm、南東柱の北面から72mm離した配置です（3Dモデル上の距離）。

## シルバー家電棚と炊飯器（2026-10-04）

レンジ・ポットの木製棚を、幅1500×奥行650×高さ1770mmの大きなステンレス風ラックに置き換えました。ヘアラインの棚板、折り返しの縁、丸パイプ脚、棚受け金具をモデル化しています。床から約1000mmまでは前面の横棒や棚板を置かず、700mm高のゴミ箱3個を丸ごと収納しました。1050mmの段にレンジ・炊飯器・ポット、1650mmの段に皿・ボウル・マグ・グラスを置いています。最上段は撤去したまま、家電段を150mm上げてゴミ箱上の空間を約300mmに広げました。食器段も150mm上げ、全高は冷蔵庫とほぼ同じ1770mmに抑えています。棚の品番は未選定です。

炊飯器は指定の[Panasonic SR-X918E](https://panasonic.jp/suihan/products/SR-X918E.html)のブラック（-K）を想定。[公式寸法](https://panasonic.jp/suihan/products/SR-X918E/spec.html)の幅292×奥行327×高さ258mmを基準に、商品写真の丸い本体、テーパー形状のふた、フラットな操作パネル、開閉ボタンを再現しました。画面表示は固定のイメージです。「視点 → 家電棚」で拡大できます。

炊飯器の上の棚板・支持材は最低でも約1604mmで、設置面から500mmのふた開き高さ（[公式仕様](https://panasonic.jp/suihan/products/SR-X918E/spec.html)）に対して約50mmの余裕を設けています。ラックの位置とゴミ箱の収納は配置A・B共通です。

## 家庭用プリンターの配置（2026-10-04）

## ハンガーラックの作業服（2026-10-04）

北東のハンガーラックに、添付写真を参考にしたチャコールグレーの作業ジャケット5着を追加しました。長袖・立ち襟・黒い前ファスナー・胸ポケットのフラップ・袖口・縫い目を描き、布の膨らみと小さな起伏を付けています。5本のハンガーを横棒に対して90度の向きに揃え、150mm間隔で掛けています。肩・袖の形を滑らかにし、開いた立ち襟の厚み、布の細かい織りと光沢、布面に沿うポケット、ファスナーの歯と引き手も表現しています。商品型番・サイズは未指定のため、外観を近似したモデルです。90度の服が壁・箱に入らないよう、ラックを225mm、収納箱16個を310mm南へ移動しました。「視点 → 作業服」で拡大確認できます。
