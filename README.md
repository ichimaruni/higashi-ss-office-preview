# 東SSビル 6階 オフィス3Dプレビュー

ブラウザで配置・視点を切り替えられる3Dモデルです。

公開ページ: https://ichimaruni.github.io/higashi-ss-office-preview/

`index.html` を更新して `main` に push すると、GitHub Pages に反映されます。

## 中央テーブル（配置B）

候補は次の6点です。寸法と価格は画面の候補比較から確認できます。

- RUGHAUS スタンダードテーブル 1750×800×H720
- MODERN DECO skdt01（伸長時）2000×1200×H717
- ONE LUX ラウンド φ1900×H710
- ONE LUX 小判形 2200×1200×H710
- G-FIELD セラミック丸テーブル φ1600×H750
- コクヨ ビエナ MT-VD211B 2100×1050×H720

「視点 → 中央」で天板・脚・北側ワゴンを近くから確認できます。「表示 → 中央テーブルのノートPC（6台）」でPCを切り替えられ、初期状態は非表示です。表示設定と候補はブラウザに保存します。削除された候補を保存していた場合はRUGHAUSに戻ります。

50インチ画面は北側のシルバー3段ワゴンの上段、iPad電話・Bluetooth受話器は中段に置き、どちらも中央テーブルへ向けています。ワゴンはユーザー提供写真を参考にした天板幅550×奥行400mmの配置検討用モデルです（モニター台座は480×310mm）。天板の高さは候補テーブルに揃え、背面の電源タップから床のT7まで延長ケーブルを描いています。ワゴンの商品選定・施工配線を確定したものではありません。
